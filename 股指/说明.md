# 股指竞价判断：规则说明

只管中金所 IF、IC、IM。从商品版的竞价判断复制出来（2026-11-18），判断骨架一字不改，只改了下面这些。

## 时间

- 任务计划「股指竞价判断」每天 9:27 启动：问标准时间、连天勤、算昨收（上一交易日收盘前 30 秒成交均价）、取近 40 个交易日的收盘价差（判「界内」用）。
- 9:29 集合竞价撮合出来，一秒内贴到博易云股指看板上；9:31 消失。
- 股指没有夜盘，竞价成交量从 0 算起。

## 门槛

| 品种 | 门槛 | 一档 |
|---|---|---|
| IF | 15 档 = 3 点 | 0.2 点 |
| IC | 20 档 = 4 点 | 0.2 点 |
| IM | 20 档 = 4 点 | 0.2 点 |

针（竞价价差 − 昨收价差）没偏出门槛 = ○ 没针。

## 符号（跟商品版一样）

- ✅ 大概率整根开到针附近；▲ 大概率开不到整根、但离昨收有段距离；❌ 大概率假；○ 没针；？ 不判断。
- 先挑 ❌：冷门腿竞价量分 + 竞价后盘口托不托得住针，合计 ≤ −1 判 ❌；立刻能成交那边偏出门槛 2 倍以上不判 ❌。
- 剩下的按内部猜的首笔（昨收价差 + 0.9 × 立刻能成交那边偏多少）分 ✅ ▲ ❌；差门槛三分之一（IF 5 档、IC IM 7 档）以内不判 ❌。
- **不显示首笔**（不出首笔估、首笔区间）；内部猜的首笔只用来分符号，csv 里照记。

2026-11-15 用两年 L2 数据把这套规则原样放到股指上试过：✅▲ / ❌ 分得开，「重几倍」最有用，「界内」有用，「腿2秒进」在 IC、IM 上有用、IF 不明显。

## 标记

| 标记 | 意思 |
|---|---|
| 紫块「重X.X」 | 竞价后立刻能成交那边偏出门槛 X 倍（≥ 2 倍才贴，≥ 3 倍更强） |
| 红框「腿2 Y」 | 腿2秒进：主力竞价跳空比腿1 小，腿2 晚进容易吃亏；Y = 主力自己跳了几倍门槛，≥ 2 倍写成「腿2❌Y」 |
| 黄框「量少」 | 冷门腿竞价不到开盘前持仓 0.7‰（只跟「重」一起出现） |
| 灰框「界内」 | 判 ✅▲ 但竞价价差没冲出近 40 个交易日的收盘价差范围，色块降一级 |
| 灰框「快交割」 | 有腿离到期只剩 2 个交易日以内（到期日 = 合约月份第三个周五，遇假日顺延），不判断 |

不看换月、不判薄大、不判小针、没有「不重」。

## 色块「重 / 打 / 小 / 关」

照商品版通用规则（没在股指上单独回放过）：判 ❌ → 关；不重 → 打；重 ≥ 3 倍 → 重，2–3 倍 → 打；有量少，重降成打；有腿2秒进 → 小（重 ≥ 5 倍且主力自己跳 < 2 倍门槛时不降）；界内再降一级。

## 竞价量小框「少 / 正常 / 大」

商品版是拿竞价成交手数跟自己的手数比。股指每格才几手，竞价量几乎总够，那样比永远是「大」，没用。所以股指改成跟这条腿**平时**的竞价量比：

竞价手数 ÷ 开盘前持仓（‰），低于下表左边 = 少，高于右边 = 大，中间 = 正常（两年 L2 里 2025-09 以后的 25%、75% 分位）：

| 品种 | 主力（腿2） | 腿1（其他合约） |
|---|---|---|
| IF | 0.75 ‰ / 1.3 ‰ | 0.25 ‰ / 0.9 ‰ |
| IC | 0.85 ‰ / 1.55 ‰ | 0.3 ‰ / 0.85 ‰ |
| IM | 0.95 ‰ / 1.6 ‰ | 0.35 ‰ / 0.9 ‰ |

主力竞价量大 = 开盘多半晃得大，正滑、负滑都多（2026-11-16 两年回放）。远季合约本来就冷，常显示「少」。
