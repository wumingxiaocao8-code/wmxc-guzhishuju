# 股指开盘指标（竞价判断 + 博易云浮层）

只管中金所股指 **IF、IC、IM**。每天 9:29 集合竞价一出结果，在博易云股指价差看板的每个格子上贴：

- **✅ ▲ ❌**：这根针大概率整根开到 / 开到一部分 / 是假的（○ 没针，？ 不判断）
- **色块「重 / 打 / 小 / 关」**：一眼看这格上不上手数（照商品版通用规则）
- **标记**：「重X.X」（立刻能成交那边偏出门槛几倍）、「腿2秒进」（主力动得少，腿2 晚进容易吃亏）、「量少」、「界内」、「快交割」
- **竞价量小框**：两条腿竞价量比平时「少 / 正常 / 大」

门槛 IF 15 档（3 点）、IC、IM 20 档（4 点）。不算首笔。9:31 自动消失。全部是脚本按规则算的，不调用 AI。

跟商品版（[qihuoshuju1](https://github.com/wumingxiaocao8-code/qihuoshuju1)）分开放，两个都装也互不影响。规则详见 [股指/说明.md](股指/说明.md)。

**只是线索，不是买卖建议。**

## 怎么装、怎么更新

把 [安装说明.md](安装说明.md) 交给你电脑上的 AI 助手（Claude Code、Codex 等），说「照这个装股指开盘指标」。
以后有新版本，跟 AI 说「更新股指开盘指标」，它会运行 `更新.ps1`。每次改了什么见 [更新记录.md](更新记录.md)。

需要：Windows、博易云、Python 3.13、自己的快期账户（天勤 TqSdk 取行情用）。
